Overview

Refrakt Custom Cuts is a beautiful, responsive photo gallery for showcasing gemstones. It's built as a static website that runs on GitHub Pages - no server or database required.

Features

  • Responsive Grid Layout - Looks great on desktop, tablet, and mobile
  • Interactive Lightbox - Click any gem to view full details and multiple photos
  • Image Gallery - Support for multiple images per gemstone
  • Search & Filter - Find gems by species, color, origin, or cut name
  • Professional Design - Clean aesthetic suitable for jewelry shoppers
  • Accessible - Keyboard navigation and screen reader support

Live Site

Once deployed, your gallery will be available at:

https://yourusername.github.io/gemcatalog/

Replace yourusername with your GitHub username.

Adding New Gemstones

Step 1: Create an Image Folder

Create a new folder in images/gems/ for your gemstone:

mkdir images/gems/tourmaline-001

Naming Convention

Use the format {species}-{number} for folder names. Examples: sapphire-001, garnet-002, tourmaline-001

Step 2: Add Photos

Copy your gemstone photos into the folder. You'll specify which images to display in the JSON file.

Step 3: Edit gemstones.json

Open data/gemstones.json and add a new entry to the array:

{
  "id": 4,
  "species": "Tourmaline",
  "color": "Blue-Green",
  "weightCarats": 2.15,
  "dimensions": "8.1x6.3x4.9mm",
  "outline": "Oval",
  "cutName": "Portuguese Cut",
  "sourceGeo": "Paraiba, Brazil",
  "isMined": true,
  "dateCut": "2024-11-15",
  "notes": "Exceptional neon blue-green color...",
  "imagesPath": "images/gems/tourmaline-001",
  "defaultImage": "main.jpg",
  "additionalImages": ["side.jpg", "detail.jpg"],
  "price": 12500
}

JSON Field Reference

Field Type Description
id number Unique identifier (increment from last entry)
species string Gem species (Sapphire, Ruby, Garnet, etc.)
color string Primary color (Blue, Green, Pink, Padparadscha)
weightCarats number Weight in carats (decimal)
dimensions string Length x Width x Depth in mm
outline string Shape (Oval, Cushion, Round, Pear, etc.)
cutName string Cut design name
sourceGeo string Geographic origin (if natural)
isMined boolean true for natural, false for lab-created
dateCut string ISO date when cut (YYYY-MM-DD)
notes string Description, characteristics, certifications
imagesPath string Path to the gem's image folder
defaultImage string Filename of the primary/card image
additionalImages array Array of additional image/video filenames (.jpg, .png, .mp4, .webm, .mov)
price number Price in USD (whole number)

Google Sheets Data Entry

For easier data entry with voice typing support, use the included CSV template:

Setup

  1. Open Google Sheets
  2. File → Import → Upload gemstones-template.csv

Voice Typing

  1. Click a cell and press Ctrl+Shift+S (or Tools → Voice typing)
  2. Speak your data, press Tab to move between fields
  3. For additionalImages, separate filenames with | (pipe)
  4. For isMined, use TRUE or FALSE

Convert Back to JSON

# Download as CSV from Google Sheets (File → Download → CSV)
# Save as gemstones-template.csv, then run:
python3 csv-to-json.py gemstones-template.csv

Adding Gem Photos & Videos

Recommended Image Specifications

Property Recommendation
Format JPEG (.jpg) for photos
Dimensions 1200x1200px or larger
Quality 80-85% JPEG quality
File Size Under 500KB per image
Color Space sRGB for web

Video Specifications

The gallery supports short videos to showcase sparkle and fire:

Property Recommendation
Format MP4 (.mp4), WebM (.webm), MOV (.mov)
Duration 5-15 seconds ideal
Resolution 1080p or 720p
File Size Under 10MB per video

Videos play automatically with loop in the lightbox and show a play icon on thumbnails.

Suggested Photo Angles

  • main.jpg - Hero shot, face-up view showing brilliance
  • side.jpg - Profile view showing depth and pavilion
  • back.jpg - View of the pavilion/bottom
  • detail.jpg - Macro shot showing special features
  • scale.jpg - Photo with size reference
  • sparkle.mp4 - Short video showing light play and fire

Photography Tips

  • Use diffused lighting to show color accurately
  • Neutral gray or white background works best
  • Ensure the table (top facet) is sharp
  • Use consistent lighting across all gems

Creating Thumbnails

The gallery uses your full-size images for thumbnails. For optimal performance, consider optimizing your images.

Using ImageMagick (Command Line)

# Install
brew install imagemagick  # macOS
sudo apt install imagemagick  # Ubuntu

# Resize and optimize
convert input.jpg -resize 1200x1200 -quality 85 output.jpg

# Batch process
for f in *.jpg; do convert "$f" -resize 1200x1200 -quality 85 "opt_$f"; done

GUI Tools

  • macOS: Preview (built-in), ImageOptim (free)
  • Windows: IrfanView, FastStone Photo Resizer
  • Online: Squoosh.app, TinyPNG.com

Local Development

Option 1: Python (Recommended)

# Navigate to project
cd gemcatalog

# Start local server
python3 -m http.server 8000

# Open browser
open http://localhost:8000

Option 2: VS Code Live Server

  1. Install the Live Server extension
  2. Open the project folder in VS Code
  3. Right-click index.html → "Open with Live Server"

Option 3: Node.js

npx serve

Troubleshooting

Images not loading?

  • Check file paths in gemstones.json match actual folder/file names
  • Ensure you're using a local server (not file://)
  • Check browser console (F12) for 404 errors

JSON errors?

  • Validate at jsonlint.com
  • Check for missing commas, quotes, or brackets
  • Ensure id values are unique

GitHub Pages Setup

Initial Setup

  1. Create a GitHub repository named gemcatalog
  2. Push your code: 
    git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/yourusername/gemcatalog.git
git push -u origin main
  3. Enable GitHub Pages:
    • Go to Settings → Pages
    • Source: Deploy from a branch
    • Branch: main / root
    • Click Save
  4. Wait 1-2 minutes, then visit your site!

Updating the Site

After making changes locally:

# Stage changes
git add .

# Commit with message
git commit -m "Add new tourmaline gemstone"

# Push to deploy
git push

Quick Commands

# Add a new gem
git add data/gemstones.json images/gems/
git commit -m "Add [gem name]"
git push

# Update gem details
git add data/gemstones.json
git commit -m "Update [gem name] details"
git push

Deployment Time

Changes typically appear on the live site within 1-2 minutes after pushing.
